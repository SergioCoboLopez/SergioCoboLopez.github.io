## Course Overview

This course provides a comprehensive introduction to data science principles and practices. Students will:

- Learn some notions of electromagnetism applied to communications
- Distinguish basic types of primary and secondary surveillance radars
- Learn basic features of the GPS systems and Navigation systems as well
